# 排口负荷与混凝投加离线复核台

澄川水务集团某污水厂的两块离线复核工具，断网可完整运行：

1. **排口污染负荷**：接入账与文件指纹、点位/设备实例、校准系数与状态有效期、片段编织与来源链、
   自然日/月污染负荷与不确定范围、覆盖率与申报资格、迟到读数的锁定窗口复算候选。
2. **混凝剂投加效率**（本迭代新增）：点位映射与池容/停留时间范围/回流比、按当时流量推导的可达出水窗口、
   泵脉冲投加与储罐混合比例、库存转移与盘点平衡、工况分段、缺料/计量不确定/工况突变/待取样四类归因、
   班次复盘与迟到化验候选。

技术栈：**React 19 + TypeScript 5.9 + IndexedDB(idb) + WebWorker + Vite 7**。
所有重计算在 Worker 内完成，主线程只读写本地库与渲染；数据不出本机。

### 4.2 混凝计算口径（`src/coag/engine.ts`）

- **可达出水窗口**：投加时段内按时间加权平均进水流量 `Q`，液压流量 `Q×(1+回流比)`，
  停留 `V / (Q(1+r)/3600)`；取 `[max(推导下限, 允许最短), min(推导上限, 允许最长)]` 作为窗口；
  推导区间完全落在允许范围外时该段不可配对。水位/池容不确定度（CT-01 4%、CT-02 5%）计入窗口宽度。
- **投加量**：只认泵脉冲：`体积 = 脉冲数 × 校准脉冲体积`；浓度按储罐混合比例（期初盘点 + 转罐/稀释按时间重放，
  投加抽液也占用液位）。校准中途失效时取“记录值 / 旧校准 / 新校准”三者的范围，并标记不可排名。
- **库存平衡**：`期初 + 入库 + 转罐净额 − 投加 ≈ 盘点期末`；采购入库量只进批次账与班次参照。
- **去除率**：窗口内进水（投加时段）与出水（窗口，截止到零点）的时间加权均值，扣除进出水仪表不确定度；
  单位药耗 = 去除质量 / 有效成分投加量。
- **排名限制**：旁路（任一分量）、缺料（脉冲 < 设定 20%）、泵校准失效、出水覆盖 <60%、搅拌改变、窗口越日终点
  任一成立即不可与正常段排名，也不会并入汇总；短片段（<90 分钟）只作参考。
- **工况分段**：先并入旁路/搅拌/突变的切换点，再以 5 分钟取样检测流量 ±20%、pH ±0.3、温度 ±1.5 ℃、浊度 >2.5 倍
  中位数的持续偏离；段内事件（含 MINOR）即判受限。
- **迟到化验**：`receivedAt > 复盘截止` 的化验只生成候选，标注影响配对与类别；当班处置从不改写
  （`shiftActionsOverwritten=false`）。当班已登记“待回结果”的化验到达后叠加“待取样”类别。

## 5. 计算口径（与引擎一致）

- 时间轴：`alignedAt = sampledAt + clockOffsetMs`，自然日按 Asia/Shanghai（UTC+8）。
- 片段边界：自然日端点、仪表实例/绑定交接、校准生效、状态切换、采样空档端点。
- 状态：仅 `OK` 可积分；`FLUSH/CALIB/BYPASS/FAULT` 整段排除并保留状态 ID。
- 采样空档：同一实例相邻有效读数间隔 > `nominal × 2.5`；空档自「上一读数 + 一个标称间隔」
  起算。段端最多保持一个标称间隔，不跨校准系数插值。
- 负荷：`∫ c(t)·q(t) dt / 3.6e6`（mg/L × m³/h × 秒 → kg）。
- 不确定范围：逐片段相对不确定度平方和开方 × `k`（默认 2）；重采样路线额外叠加
  梯形法解析误差界 `|c′q′|h³/6`。
- 覆盖/资格：覆盖率 = 有效积分秒 / 86,400；低于申报线 15pp 以上判不可申报。

### 两条积分路线

| | 逐有效片段积分（默认） | 经误差界验证的重采样积分 |
| --- | --- | --- |
| 局部证据 | 每个片段保留读数/校准/状态/文件 | 保留边界，片段内网格化 |
| 窄事件 | 40 s 冲击边界精确到读数时刻 | 需斜率上界 + 细分，否则会漏检 |
| 汇总成本 | 片段与结点多，查询较重 | 网格单元轻，便于跨层聚合 |
| 证明责任 | 无需额外证明 | 必须证明负荷范围、峰值、阈值穿越不变 |

核验阈值（`src/domain/engine.ts`）：负荷相对偏差 ≤0.5%，1h 峰值窗口中心偏移
≤ max(30 s, 1 网格)，阈值穿越并集对称差 ≤2 s，网格细分后无未决单元。

## 6. 申报与迟到复算

1. 「覆盖与资格」出具申报 → 生成 `FILED` 版本；截止接收时刻默认取该点位当日数据集的
   最大 `receivedAt`（样例为 2026-11-19 07:20），并锁定来源窗口、
   来源读数 ID 快照与来源文件指纹。
2. 「复算候选」导入迟到补录 → 读取落在锁定窗口内且 `receivedAt > 截止` 的读数。
3. 生成候选：只把迟到读数并入重算，原申报版本**不做任何修改**（`declarationOverwritten: false`），
   候选保存 `baseline` / `recomputed` / `diff` 与受影响片段。
4. 人工填写复核附注并标记 `REVIEWED`；是否作为下一版申报依据由人工决定。

## 7. 混凝投加的业务判断

- **两种汇总路径**：按班次（操作人员便于对照交接记录）会把班内暴雨/切换混合成平均，班次越短越容易被单次事件主导；
  按稳定工况更接近实际反应，但会产生短片段与未覆盖时段（样例 CT-01 未覆盖 565 分钟、CT-02 217 分钟）。
  两条路径都只使用本条推导的对应窗口，并按当日实际投加（脉冲）归一化。
- **不能拿入库量当投加**：09:00/11:45 的批次入库量 404 kg 纳入批次账与库存平衡；实际投加按脉冲为
  CT-01 151.9 kg、CT-02 79.2 kg。把入库量当投加会得到随补货节奏跳动的“效率”，样例页会并列展示这个反例。
- **储罐混合比例**：06:40 补清水后浓度从 42 g/L 降到 37.43 g/L（液位被投加抽走，稀释倍数随之变化），
  07:10 转罐混入 40 g/L 批次后回到 37.90 g/L；每次转罐记录都给出动作后浓度，供核对。
- **旁路/校准失效只给范围**：CT-01 16:30–17:10 的配对窗口标为不可用、不可排名；CT-02 09:40–10:20 校准失效段
  体积给 29.1–33.4 L 的范围，并停止与正常段排名。
- **迟到化验**：11-19 到达的 3 条化验（10:15 出水样、20:30 低温留样、07:00 药剂样）只生成候选；
  当班处置（如“10:15 出水样已送第三方，结果未回”）保持不变。

## 9. 已知边界

- 样例覆盖 2026-11-18 单日；月度页会明确显示「有数据 1 天 / 缺 29 天」，不补零。
- 时钟校正量来自设备台账的固定值；时钟漂移本身未建模，但偏移不确定度计入区间说明。
- 流量与浓度读数均取自一个排口的同一时刻对齐序列；跨厂站对比仅做展示，不合并负荷。
- 本工具不替代法定监测数据有效性判定，只提供可追溯的复核证据与缺口量化。
- 混凝模块的停留时间按“有效池容 / 液压流量”估算，未单建推流/扩散模型；流量在窗口内取时间加权平均，
  不是逐秒积分。出水窗口跨过零点时只用当天数据，次日读数需要次日资料才能配对（样例中 23:00 投加即属此类）。
- 储罐浓度按批次标称值与混合比例推导，化验值仅作核对展示；盘点误差固定为千分位级，不模拟人为盘点波动。
- 混凝样例的班次为固定 8 小时三班；如果现场采用 12 小时班或跨零点交接，需要在 `shifts.csv` 调整起止分钟。
